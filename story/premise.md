# 物語概要とテーマ

## 作品の軸

仮称は「自律AIファンタジー世界」。舞台の成り立ちは[世界概要](../world/overview.md)を参照。

一人の主人公の冒険ではなく、何百年、あるいは何千年にもまたがる複数世代の物語である。中心の問いは、**この世界の外側は存在するのか**。

「実はゲーム世界だった」という事実の開示自体を最終目的にはしない。重要なのは、そこで何千年もの歴史を生きた者たちの人生である。

## 作品全体の問い

- 人工的に作られた世界であれば、その人生は偽物なのか。
- 作られた知性に自由意志は存在するのか。
- 世界の創造者と、世界を管理する者のどちらが神なのか。
- 神が管理プログラムだった場合、信仰には意味がないのか。
- 世界の物理法則がプログラムだった場合、それを知ることは世界を否定することなのか。
- 自分たちより巨大な世界の存在を知ったとき、それでも自分たちの世界で生きることには意味があるのか。

## 三章の問い

| 章 | 中心となる問い |
| --- | --- |
| 第一章 | 外は存在するのか。 |
| 第二章 | 外が存在すると知ったとき、どうするのか。 |
| 第三章 | 外にいる者へ、自分たちの存在を伝えることができるのか。 |

三人の主人公は、異なる段階で問いに向き合う。第一章と第二章の主人公の生存時期は重なるが、二人は生前に出会わず、第二章は第一章の主人公の死から間もなく始まる。第二章と第三章の間には長い時間が経過する。三人の主人公を軸とする構成であり、連続する親子三代ではない。
