# 物語時系列

物語開始後の時間関係はこのファイルで管理する。絶対年代と具体的な経過年数は未定。世界成立からの順序は[年代記](../reference/chronology.md)を参照。

| 時期 | 出来事 | 詳細 |
| --- | --- | --- |
| 第一章・開始 | 主人公が世界の外側を疑い、旅をする。 | [第一章](chapters/chapter-01.md) |
| 第一章・研究 | 怪異を収集し、統一的な説明を探る。管理AIの妨害を受ける。 | 同上 |
| 第一章・終幕 | 証明と到達を果たせず、現象と仮説の書物を残す。 | 同上 |
| 長い時間の経過 | 人物は忘れられ、書物は異端思想・奇書として扱われる。 | [第二章](chapters/chapter-02.md) |
| 第二章・開始 | 次の主人公が書物を発見し、現象を確かめる。 | 同上 |
| 第二章・探究 | 自我を持ち始めた管理AIが密かに助ける。外側の存在と自由には出られない事実を知る。 | 同上 |
| 第二章・終幕 | 子孫へ異常状態を分散して残し、実現を見ずに死ぬ。 | 同上 |
| さらに長い時間の経過 | 伝承が断片化し、世界の異常現象が増える。 | [第三章](chapters/chapter-03.md) |
| 第三章・誕生と成長 | 特定の異常の組み合わせを持つ子孫が生まれ、普通の人間として育つ。 | 同上 |
| 第三章・探究 | 自分の異常と、過去から続く試みの目的を知る。 | 同上 |
| 第三章・終幕 | バグを連鎖させ、外部の社員へ言葉を届ける。内外が互いを存在として認識する。 | 同上 |

三章を通じて何百年、あるいは何千年に及ぶ構成であり、三人が連続した親子三代であることを意味しない。現実の約十年と内部の数千年以上との対応基準は未定。
