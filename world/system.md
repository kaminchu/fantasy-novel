# システムの基本構造

世界は以下の五層によって支えられている。層の名称や技術的説明は作者側の設定であり、住人が理解している知識ではない。

| 層 | 名称 | 役割 |
| --- | --- | --- |
| 第一層 | 世界シミュレーション | 物理法則、地形、気象、生態系、魔法を処理する。住人にとっての現実そのもの。 |
| 第二層 | 生物AI | 人間、エルフ、ドワーフ、ゴブリン、動物、魔物などを動かす。生物によってモデルの規模や能力が異なる。 |
| 第三層 | 世界管理AI | 人口、生態系、気象、災害、計算資源などを監視・調整し、長期的な安定稼働を支える。内部では神と認識される場合がある。 |
| 第四層 | 外部入出力システム | 企業側の別システムとの接続口。開発時の実験機能や別用途に流用された機能が残り、仕事の入力と結果の返却ができる。 |
| 第五層 | 企業の計算基盤 | 現実世界のサーバー群。世界は巨大企業の計算資源のほんの一部として存在する。 |
